# Rudransh Food Venture — HTML Website

A responsive, single-page HTML/CSS/JavaScript website inspired by the supplied Rudransh product artwork and the structure/style direction of the referenced Country Dairy site.

## Files
- `index.html` — website structure
- `styles.css` — responsive styling
- `script.js` — product data, cart and WhatsApp enquiry
- `assets/rudransh-products.jpg` — your supplied product/brand artwork

## Run locally
Open `index.html` in a browser. No build step is required.

## Important customizations
1. Open `script.js`.
2. Set real product prices in the `products` array.
3. Replace `919999999999` with your actual WhatsApp Business number.
4. Update email/phone/address in `index.html`. WhatsApp ordering is configured for +91 93374 12622.
5. Product cards now use separate crops for Laddu, Burfi, Peanut Laddu, Peanut Burfi and Shakti Protein Powder.
